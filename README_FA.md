# ایزومر سه‌بعدی — نسخهٔ اولیه

این پروژه یک پوستهٔ اندرویدی با رابط فارسی و نمایشگر سه‌بعدی آموزشی است.

## ساخت APK با Android Studio
1. Android Studio نسخهٔ جدید را نصب کن.
2. این پوشه را با گزینهٔ **Open** باز کن.
3. اجازه بده Gradle و Android SDK موردنیاز نصب/همگام‌سازی شوند.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کن.
5. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکته‌ها
- برای بارگیری کتابخانهٔ Three.js در اجرای برنامه، اتصال اینترنت لازم است.
- مدل‌های فعلی شماتیک و نمونه‌ای هستند؛ این نسخه هنوز بانک جامع ایزومرها، نام‌گذاری خودکار IUPAC، یا تعیین محاسباتی R/S ندارد.
- برای افزودن مدل‌های دقیق‌تر می‌توان در مرحلهٔ بعد از داده‌های ساختاری معتبر (مانند SMILES و مختصات سه‌بعدی) استفاده کرد.
